# Finishing a Development Branch

**Core principle: Verify tests → Present options → Execute choice → Clean up.**

## Steps
1. **Verify Tests**: Must pass before proceeding.
2. **Determine Base Branch**: (main/master).
3. **Present 4 Options**:
   - 1. Merge locally
   - 2. Push and create PR
   - 3. Keep branch as-is
   - 4. Discard work (confirm with "discard")
4. **Execute Choice**: Perform git operations.
5. **Cleanup Worktree**: Remove worktree for options 1, 2, 4.
