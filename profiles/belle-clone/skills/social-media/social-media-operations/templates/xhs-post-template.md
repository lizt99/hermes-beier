# Xiaohongshu Post Template

## Structure

### 1. Cover (Visual)
- **Primary Image**: High-contrast text on a real-life background (e.g., a notebook or calculator).
- **Hook Headline**: Use "Fear" or "Benefit" hooks. 
  - *Example*: "Debt 50W, the phone call that saved 3W interest."

### 2. Title (Text)
- Use Emojis to break up text.
- Include a "Number" or "Result."
- *Example*: ‼️负债上岸：银行不告诉你的3个协商真相㊙️

### 3. Body Content
- **Pain Point**: Acknowledge the struggle.
- **Value/Solution**: Step-by-step guide or "Hardcore" value.
- **Call to Action**: "Save this if you're struggling" (收藏防走丢).
- **Hashtags**: #负债上岸 #还债日记 #理财 #上岸

### 4. Interactive Layer
- **Comment Hook**: Ask a question like "Which bank are you struggling with?"
