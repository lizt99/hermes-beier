# WeChat Debt-Support Group Operations

Demoted from the former standalone `wechat-debt-support-group-ops` skill into the broader `social-media-operations` umbrella because it is a domain-specific private-domain/community-ops variant rather than a separate class of agent capability.

## Original positioning
Use when operating a WeChat community with the group owner as the central operator, coordinating intake, trust-building, service routing, conversion, and compliance/risk control for debt-stressed users entering from public platforms.

## Core model
Treat the group like a service mall:
- group = traffic field
- group owner = operations desk / property manager
- service roles = specialized stores
- private chat = consultation room
- delivery = fulfilled order

## Key operating responsibilities
- welcome and onboarding
- rule broadcast and moderation
- atmosphere management
- anti-spam / anti-competitor handling
- topic scheduling
- lead tagging and routing
- complaint handling
- daily and weekly review

## Funnel phases
1. Public traffic intake
2. Group onboarding and order establishment
3. Trust building and activity design
4. Need identification and routing
5. In-group service appearance
6. Private conversion SOP
7. Delivery and retention

## Useful models retained from the original skill

### Three-layer tagging
- state tag: calm / anxious / panic / confrontational / withdrawn
- need tag: emotional / income / legal-process / mixed
- conversion tag: cold / warming / consult-ready / high-risk

### Decision framework
Classify tactics as:
- Scale
- Hold
- Optimize
- Stop

### Default deliverables
- group positioning
- onboarding SOP
- welcome messages
- group rules
- daily topic calendar
- service-role design
- need-tagging framework
- private chat conversion scripts
- packaging suggestions
- dashboards
- risk-control rewrites
- task assignments
- feedback collection formats
- next-step decision memos

## Compliance notes
- no fabricated credentials or cases
- no exploitative panic conversion
- no guaranteed debt/legal outcomes
- do not misrepresent paid services as official institutions or licensed representation
- use clear disclaimers for legal/info boundaries
- escalate severe emotional-risk users to qualified help when needed

## Consolidation note
This material remains valuable, but as a reference bank under the broader social-media/private-domain operations class rather than as its own top-level skill.
