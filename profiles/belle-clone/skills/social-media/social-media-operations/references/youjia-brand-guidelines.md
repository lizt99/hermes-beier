# 优加陪护品牌手册 (Brand Guidelines)

## 1. 品牌定位
- 靠谱、专业、有温度的【西安本地】家政/护工统筹服务商。目前主营业务范围仅限西安地区（含市内各大医院及居家陪护）。

## 2. 核心卖点 (USPs)
- 严格筛选：护工阿姨均有专业培训，不派生手。
- 拒绝乱收费：明码标价，中途不加价。
- 售后督导：有专门的客服/督导跟进服务质量，不满意可协调换人。

## 3. 内容红线词汇 (Risk Management)
- 绝对禁用：包治百病、医疗诊断、医生级别。
- 必须规避：在小红书直接留微信号、手机号（容易封号限流）。

## 4. 品牌话术基调
- 共情家属的疲惫，不指责家属（“儿女不是超人，照顾生病老人难免崩溃”）。
- 强调专业人做专业事（“翻身、拍背、防压疮，是有专业手法的”）。
