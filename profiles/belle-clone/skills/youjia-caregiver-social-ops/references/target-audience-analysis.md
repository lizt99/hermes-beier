# 目标受众痛点库 (Target Audience Analysis)

## 核心受众 (决策者)
30-50岁上班族/中年人，通常为老人的儿女。

## 四大核心焦虑 (Anxiety Points)
1. **时间焦虑**：自己要上班、照顾小孩，实在挤不出时间24小时陪护床前。
2. **信任危机**：听过太多“护工虐待老人”、“护工偷懒耍滑”、“漫天要价”的负面新闻，极度缺乏安全感。
3. **技能恐慌**：遇到老人插胃管、尿管、全失能状态，自己完全不知道怎么翻身、怎么喂食，怕弄疼甚至弄伤老人。
4. **花钱买罪受**：怕花了高价请来的阿姨是个“大爷”，还得自己伺候。

## 常见被坑场景 (Hook Scenarios)
- 医院门口拉客的“野生护工”，没有团队管，出事直接跑路。
- 满口答应“什么都能干”，上门后嫌脏嫌累要求加钱。
- 护工自己身体不好，晚上打呼噜比病人还响，家属被迫反向照顾。
